# 💣 Classic Windows 95 Minesweeper (클래식 지뢰찾기)

순수 HTML5, CSS3, Vanilla JavaScript만으로 구현된 클래식 윈도우 95 감성의 정통 지뢰찾기 웹 게임입니다.  
외부 의존성(CDN, 외부 폰트, 이미지 등) 없이 단일 파일(`index.html`)로 어디서든 브라우저만 있으면 오프라인에서도 즉시 동작합니다.

---

## ✨ 주요 기능 및 특징

1. **클래식 윈도우 95 레트로 감성 베벨(Bevel) UI**
   - 윈도우 95/98 정통 실버 회색(`rgb(192, 192, 192)`) 테마
   - 3D 돌출(Raised) 및 오목(Inset) 입체 베벨 테두리 효과
   - 4단계 감정 표현 스마일리 리셋 버튼 (평상시 😊, 타일 누름 😮, 패배 😵, 승리 😎)

2. **외부 폰트 없는 순수 CSS 7세그먼트 빨간색 LED 디스플레이**
   - `linear-gradient`만을 활용해 구현한 클래식 디지털 7세그먼트 LED
   - 좌측: 실시간 남은 지뢰 카운터 (음수 대응)
   - 우측: 실시간 경과 시간(초) 타이머

3. **정밀한 게임 코어 엔진 (`MinesweeperEngine`)**
   - **첫 클릭 안전 보장 (First Click Safe Zone)**: 사용자가 처음 클릭한 칸과 그 인접 8칸에는 지뢰가 절대 배치되지 않도록 동적 생성 (절대 첫 클릭에 죽지 않음).
   - **반복문 기반 안전한 Flood-Fill 알고리즘**: 빈 타일 개방 시 스택 오버플로우 없는 주변 빈 칸 자동 연쇄 오픈.
   - **깃발(🚩) 및 물음표(?) 순환 토글**: 우클릭으로 손쉬운 타일 마킹.
   - **Chord (주변 일괄 오픈)**: 열린 숫자 타일 주변에 필요한 수만큼 깃발이 꽂혀있을 때 더블클릭으로 안전한 주변 타일 일괄 개방.
   - **숫자 1~8 클래식 고유 색상 및 폭발 하이라이트**.

4. **3단계 난이도 프리셋**
   - **초급 (Beginner)**: 9 × 9 격자, 지뢰 10개
   - **중급 (Intermediate)**: 16 × 16 격자, 지뢰 40개
   - **고급 (Expert)**: 16 × 30 격자, 지뢰 99개 (반응형 가로 스크롤 뷰포트 지원)

## 🚀 실행 방법

별도의 설치나 빌드 과정 없이 `index.html` 파일을 더블 클릭하여 브라우저에서 바로 실행할 수 있습니다.

```bash
# 브라우저에서 바로 열기
start index.html
```

## 🕹️ 조작법

| 동작 | 키 / 마우스 | 설명 |
| :--- | :--- | :--- |
| **타일 열기** | 마우스 좌클릭 | 숨겨진 타일을 엽니다. (첫 클릭은 항상 안전) |
| **깃발 / 물음표 표시** | 마우스 우클릭 | 닫힌 타일에 깃발(🚩) ↔ 물음표(?) ↔ 해제 순환 |
| **주변 일괄 열기 (Chord)** | 더블클릭 | 숫자 주변 깃발 수가 일치할 때 나머지 주변 타일 오픈 |
| **새 게임 시작** | 스마일리 버튼 클릭 | 현재 난이도로 보드를 즉시 재시작 |
| **난이도 변경** | 상단 드롭다운 | 초급 / 중급 / 고급 즉시 전환 |
